# Artifact Gallery（交付物版本画廊）

把每次生成的交付物按"逻辑产物"维度登记版本，并用一个本地画廊页面（在 WorkBuddy 预览面板打开）呈现：

- **左栏**：本次/历次对话产生的所有产物清单（文件名），点击切换。
- **中栏**：选中产物的放大预览（iframe 实时渲染 HTML；非 HTML 给下载链接）。
- **右栏**：该产物的版本缩略图，竖向堆叠，**最新版本固定在最底部**（像 PPT 幻灯片缩略图）。
- 点击右栏任意旧版本 → **只在中栏放大查看，不改动当前文件**。
- 中栏出现"回撤到此版本"按钮，仅当用户**主动点击**时才把该版本复制回工作文件（并记为一个新版本，保留历史）。

## 何时使用
用户表达以下意图之一时触发：
- "像 NoCode 一样看我之前生成的版本 / 版本历史 / 回退旧版"
- "把每次对话生成的文件都列出来、可以点开看、能回撤"
- 任何需要对比同一交付物多版迭代、或担心改坏想保留回退点的场景。

## 核心约定（务必遵守）
1. **登记时机**：每当你为用户生成/修改完一个交付文件（尤其是 HTML 报告、Word、PPT），**立即运行 `scripts/register_version.py` 登记一版**。
2. **稳定的 artifact_id**：同一个逻辑产物（例如"美团无人车价格策略运营_简历适配版"）始终用同一个 `artifact_id`，这样多次修改会**累积成版本时间线**；不同产物用不同 id。id 可省略，脚本会用文件名自动生成 slug。
3. **不要自动回撤**：回撤是破坏性操作，只能由用户在画廊页面显式点击"回撤到此版本"触发，或在对话中明确要求"回退到 vN"。AI 不得擅自把旧版本覆盖回工作文件。
4. **数字与事实守恒**：登记/回撤只是文件副本管理，不改变文件内容语义；沿用既有口径规则（905 简历为准等）。

## 使用流程
### 1. 登记一次产物
```bash
py scripts/register_version.py "<交付文件路径>" "<一句话描述本版改动>" [artifact_id] [显示名] [工作文件路径]
```
例：把刚写好的简历适配版登记为 v1（id 自动取文件名 slug）：
```bash
py scripts/register_version.py "D:/intern/面试/美团无人车价格策略运营_简历适配版.html" "初始版本"
```
若已存在同名 id，则自动追加为 v2、v3……形成时间线。

### 2. 生成画廊（推荐·离线/可移植）
```bash
py scripts/build_gallery.py
```
生成单文件 `gallery_standalone.html`（默认在 `$ART_ROOT/gallery_standalone.html`，可指定输出路径）。**直接用 `present_files` 打开这个文件即可**，无需任何服务器、全平台可用，也最方便拷到别的电脑查看。每次登记新版本后重新跑一次本命令即可刷新。

### 3.（可选）实时回撤模式
若想要"中栏回撤按钮直接把旧版本写回工作文件"，需本地起服务：
```bash
py scripts/gallery_server.py
```
浏览器打开 `http://localhost:8731`（用 `present_files` 传该 URL），回撤按钮会真正复制文件；离线版则点回撤只会复制回撤指令文本，由 AI 执行。

### 4. 查看 / 对比 / 回撤
- 左栏点产物名 → 右栏出现该产物所有版本缩略图，**最新在底部**。
- 点右栏旧版本 → 中栏放大预览（**不回撤**）。
- 离线版点"回撤"→ 复制回撤指令发给 AI，AI 用 `register_version.py` 的回撤逻辑把该版复制回工作文件并记新版本；实时模式下点回撤按钮直接完成。

## 数据存储
- 清单：`$ART_ROOT/manifest.json`（`ART_ROOT` 环境变量可改，默认 `D:\intern\.workbuddy\artifacts`）。
- 快照：`$ART_ROOT/<artifact_id>/v<N>_<时间戳>.<ext>`。
- 工作文件（`current_path`）即用户日常编辑的原始路径；回撤时旧快照会被复制回此处。

## 典型场景：同一个交付物跨对话迭代（最主要用法）
用户最常见的需求不是"列出所有文件"，而是**一个逻辑交付物在多次对话里被反复修改，留下版本时间线**。本技能对此是原生支持的——关键在于"稳定 artifact_id"：

- 例如"无人车价格策略运营·简历适配"这个交付物，在对话 A 生成初稿 → 登记为 `简历适配_无人车价格策略` v1；
- 对话 B 按反馈改写 → 用**同一个 id** 再登记一次 → 自动变成 v2；
- 对话 C 又改一版 → v3。右栏就会竖向堆叠 v1/v2/v3，**最新 v3 在最底部**，点 v1/v2 只预览不改动，点中栏"回撤"才把某版恢复。
- **不同逻辑交付物**才用不同 id（如"跑腿骑手简历适配""生鲜简历适配"各一个 id）。

所以登记时务必对"同一个东西"复用同一个 id；id 决定版本是否累积到一起。

## 注意事项
- **首选离线版** `gallery_standalone.html`：单文件、无需服务器、可直接用 `present_files` 打开，适合本机查看与跨电脑携带；其中"回撤"仅复制指令、由 AI 执行。
- 想要"回撤按钮直接写文件"才需要 `gallery_server.py`（本地 HTTP 服务）。服务在某些沙箱/网络隔离环境下可能不稳定，离线版更稳。
- 非 HTML 产物（docx/pptx）中栏预览显示为下载按钮，右栏缩略图显示占位卡，不影响版本管理。
- 版本数据存于 `manifest.json` 与各快照目录，与技能本身分离；迁移历史时连同 `$ART_ROOT` 一起拷贝。
